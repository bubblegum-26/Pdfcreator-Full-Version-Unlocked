## Main Features
<a id="main-features"></a>

### Core Functionality
- **Virtual Printer Installation** — Installs a virtual printer that allows users to print any document to PDF format directly from any application. Simply select PDFCreator as your printer to convert.
- **Multiple Format Support** — Transforms documents into various formats including PDF, PNG, JPEG, BMP, PCX, TIFF, PS, EPS, TXT, PSD, PLC, Raw, or SVG.
- **Document Combining** — Offers the ability to merge multiple documents into a single PDF file, streamlining document management.
- **Metadata Editing** — Users can include essential information like author and creation date in the PDF, enhancing organization and documentation.
- **Context Menu Integration** — Provides right-click options for easy access, allowing users to convert files to PDF without opening additional applications.

### Advanced Capabilities
- **File Compression** — Compress and resize images within documents to reduce overall file size without sacrificing quality.
- **AES Encryption** — Protect sensitive information in PDFs with AES encryption, ensuring privacy and security.
- **Dropbox Integration** — Upload files directly to Dropbox upon saving, enhancing workflow efficiency.
- **Printing Monitor** — A built-in monitor displays the list of documents queued for conversion, allowing for better management of conversion tasks.
